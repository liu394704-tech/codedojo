# CodeDojo · 代码道场

一个在真实开源代码上训练代码阅读能力的本地训练站：每日任务、限时阅读、闭卷三行总结、语法卡片台账、AI 代码病灶笔记。

**在线使用**：打开 `trainer/` 目录（GitHub Pages 地址见仓库 About 区域的链接）。

**训练方法**：计时 20 分钟只读一个文件 → 关上代码闭卷写三行（文件意义 / 关键函数 / 没看懂的地方）→ 重开对照 → 每个不懂的语法记一张卡片。每周日过一遍卡片。完整计划见[训练手册](训练手册.md)。

进度、卡片、笔记全部存在浏览器 localStorage，不上传任何数据。
